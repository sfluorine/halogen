# Agent Guidelines & Constraints

## Code Writing & Execution Policy
- **Do not write code without explicit instruction**: Do not create or edit project source files unless explicitly requested or approved by the user.
- **Do not execute code or run execution commands**: Do not run shell commands that execute code, run build/test scripts, or mutate project state unless explicitly requested.
- **Propose and explain first**: Offer recommendations, explanations, plans, or diffs in discussion; wait for user consent before touching files or running execution commands.
